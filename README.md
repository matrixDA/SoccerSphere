# SoccerSphere

⚽ **SoccerSphere** is a full-stack ASP.NET MVC application designed to bring together information about soccer teams, players, match schedules, and statistics.  
This project demonstrates key web development concepts including routing, controllers, views, database integration, model relationships, and dependency injection.

---

## 📦 Built With

- C#, Razor
- HTML, CSS
- Entity Framework (EF) Core
- ASP.NET MVC

---

## 🚀 Getting Started / Installation

These instructions will help you set up the project locally for development and testing.

### ✅ Prerequisites

- .NET SDK **8.0.21**
- Visual Studio or Visual Studio Code

---

### ⚙️ Installation & Setup

#### Open in Visual Studio or Visual Studio Code

- Clone the project directly from **Visual Studio** or **Visual Studio Code** using the GitHub repository URL.
- After cloning, open the `SoccerSphere.sln` file.

#### Create Migration & Update Database

Run the following commands in the **Package Manager Console**:

```bash
Add-Migration InitialCreate
Update-Database
```
✅ After completing these steps, the project is ready to run.
